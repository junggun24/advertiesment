# 도메인 연결 후 SEO·AEO·GEO TODO

- [ ] `metadataBase`, canonical, Open Graph URL을 최종 도메인으로 통일
- [ ] `robots.txt`, `sitemap.xml`, Organization·WebSite 구조화 데이터 주소 통일
- [ ] Google Search Console 소유권 확인 및 사이트맵 제출
